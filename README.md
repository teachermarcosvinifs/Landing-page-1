# Site do professor Marcos Vinicius

Este repositório contém o site público de apresentação das minhas aulas particulares de inglês online, com ensino regular do iniciante ao avançado, conversação a partir do B1 e trabalho voltado a situações profissionais.

**[Conhecer as aulas de inglês online](https://teachermarcosvinifs.github.io/Landing-page-1/)**

Para consultar modalidades e exemplos do trabalho:

- [Aulas de inglês online para adultos](https://teachermarcosvinifs.github.io/Landing-page-1/aulas-de-ingles-online-adultos.html) — ensino regular e formatos individual, dupla, trio e grupo.
- [Inglês para desenvolvedores e programadores](https://teachermarcosvinifs.github.io/Landing-page-1/ingles-para-devs.html) — reuniões, explicações técnicas, documentação e comunicação no trabalho.

As aulas são online, com materiais e atividades organizados no Portal dos Alunos.
