# Site do professor Marcos Vinicius

Este repositório contém o site público de apresentação das minhas aulas particulares de inglês online, com ensino regular do iniciante ao avançado, conversação a partir do B1 e trabalho voltado a situações profissionais.

**[Conhecer as aulas de inglês online](https://teachermarcosvinifs.github.io/Landing-page-1/)**

Páginas do site:

- [Aulas de inglês online para adultos](https://teachermarcosvinifs.github.io/Landing-page-1/aulas-de-ingles-online-adultos.html) — ensino regular, do iniciante ao avançado.
- [Conversação em inglês para adultos](https://teachermarcosvinifs.github.io/Landing-page-1/conversacao-ingles-adultos.html) — aulas conversacionais a partir do B1.
- [Inglês para desenvolvedores e programadores](https://teachermarcosvinifs.github.io/Landing-page-1/ingles-para-devs.html) — reuniões, explicações técnicas e documentação.
- [Inglês para profissionais de Compliance](https://teachermarcosvinifs.github.io/Landing-page-1/ingles-para-compliance.html) — riscos, controles, auditorias e comunicação profissional.
- [Como funcionam as aulas](https://teachermarcosvinifs.github.io/Landing-page-1/como-funciona.html) — organização, materiais e acompanhamento.
- [Formatos das aulas](https://teachermarcosvinifs.github.io/Landing-page-1/qual-formato.html) — individual, dupla, trio e grupo.
- [Portal dos Alunos](https://teachermarcosvinifs.github.io/Landing-page-1/portal-dos-alunos.html) — materiais e atividades das aulas.

As aulas são online, com materiais e atividades organizados no Portal dos Alunos.
